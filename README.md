An entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun: one funny line, a single sentence of at most 200 characters.

## The line

> I bought a diary to organise my thoughts, but now it just sits there judging me in my own handwriting.

## How it works

`main.py` (Python standard library only, deterministic, no network) writes exactly that one line to `/output/entry.txt`, creating the directory if needed, with no trailing newline.

```sh
python3 main.py
```
